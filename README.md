## 功能

### 方程式配平

输入反应物与产物，自动求出最小正整数系数。

- 支持反应条件：`H₂+O₂=点燃=H₂O`
- 支持沉淀 `↓`、气体 `↑` 等后缀标注
- 支持离子方程式（电荷守恒）、水合物 `·`、络合物 `[...]`、嵌套括号
- 结果可切换**完整方程式**或**仅数字**两种显示

### 相对分子质量计算

从化学式计算相对分子质量，并逐个元素给出质量分数：

```
相对分子质量：98
————————————
其中，
H的质量分数为：(2 / 98) × 100% = 2.04%
S的质量分数为：(32 / 98) × 100% = 32.65%
O的质量分数为：(64 / 98) × 100% = 65.31%
```

可选**普通模式**（相对原子质量取整，符合中学教学口径）与**精确模式**（取标准原子量）。

### 「摩有全都有」

物质的量为核心的联动换算，改动任一格其余自动更新：

- 物质的量 `n`（mol）
- 质量 `m`（g）
- 摩尔质量 `M`（g/mol），可由化学式一键算出
- 标况气体体积 `V`（L，按 22.4 L/mol，一键恢复标况）
- 溶液体积 `V`（L）与物质的量浓度 `c`（mol/L）
- 微粒数 `N`（个）
- 小数位数可调

### 上下标转换

普通数字 ⇄ 下标 ⇄ 上标 三者互转，结果一键复制，方便粘进 Word 或聊天框。

### 输入辅助

- 化学式自动联想：输入 `H2S` 会弹出「硫酸、硫化氢、亚硫酸」等候选，`F1`~`F5`、`↑`/`↓` + 回车、或双击即可选择
- 按钮面板：常用元素、原子团、常见离子、标注符号、全部元素一键插入

### 未完成的部分

「公式格式转换」页（本程序格式 / Word 公式域 / 其他配平程序格式）在 v1.2.1 中**控件全部隐藏并标注「暂不可用」**，仅保留页面占位，尚未实现完整的双向转换。

## 配平原理

把配平问题化成线性方程组的求解问题：

1. **建矩阵**：以每种物质的系数为未知数，左侧为正、右侧为负；每种元素一行，电荷一行，右端全为 0（齐次方程组）。
2. **定标**：齐次方程组只能定出比例，所以再补一行归一化方程 `x₀ = 1`，把无穷多组解收敛到唯一一组。
3. **化简**：逐行按最大公约数约分、剔除重复行，减少消元规模。
4. **消元**：用 `frac`（分子/分母均为 `int` 的有理数）做高斯消元，全程精确运算，不引入浮点误差。
5. **校验**：解出的系数必须全部为正，否则判为无解。
6. **取整**：把分数解统一乘以各分母的最小公倍数，得到**最小正整数解**。

当方程数少于未知数时，方程组有无穷多组解。程序会先用「组合枚举子矩阵」的方式尝试找出可行解，再退化为对系数做有界暴力搜索（`DFS`），仍失败才提示：

> 部分氧化还原反应方程式无法通过元素守恒和电荷守恒求解，请尝试自己用化合价升降法配平。

## 输入语法

### 化学式

| 类型 | 示例 |
| --- | --- |
| 一般 | `Na₂SO₄` |
| 带括号 | `Ca(OH)₂` |
| 离子 | `SO₄²⁻` |
| 水合物 | `CuSO₄·5H₂O` |
| 络合物 | `[Cu(NH₃)₄](OH)₂` |

下标可用 `₂` 这类 Unicode 下标字符，也可用普通数字；电荷上标必须写在化学式末尾。
元素符号必须以大写字母开头。

### 方程式

```
反应物 + 反应物 + 反应物 = 产物 + 产物 + 产物
反应物 + 反应物 + 反应物 = 条件 = 产物 + 产物 + 产物
反应物 + 反应物 = 气体产物↑ + 沉淀产物↓
```

更多说明见 [docs/怎么输入.txt](docs/怎么输入.txt)，可直接试算的样例见 [docs/测试方程式.txt](docs/测试方程式.txt)
（含 `KNO₃+C₆H₁₂O₆=K₂CO₃+N₂+CO₂+H₂O`、`(NH₄)₆Mo₇O₂₄+KCr(SO₄)₂+H₂O=...` 等难度较高的方程式）。

## 数据文件

`Data/` 下的三个文件在运行时从 **exe 所在目录**读取，生成时会自动复制到输出目录。
修改后重新生成即可生效（联想词库改完重启程序）。

### `AtomicMass.txt` — 相对原子质量表

空格分隔，每行一个元素；以 `//` 开头的行是注释。程序读取第 3、4 列：

```
<原子序数> <中文名> <元素符号> <相对原子质量>
1 氢 H 1.00794
6 碳 C 12.0107
```

质量值若用方括号包裹（如 `[261]`，表示最稳定同位素质量数），程序会自动去掉括号。

### `Molecules.txt` — 联想词库

逗号分隔，每行一种物质；以 `//` 开头的行是注释，同一物质可写多个别名：

```
化学式,名称
H₂SO₄,硫酸
NaHCO₃,碳酸氢钠、小苏打
```

### `InputPanel.txt` — 输入面板按钮

逗号分隔，第一个字段是分组名，其余每项一个按钮；用 `/` 可把「显示文本」与「悬停提示」分开：

```
下标,₀,₁,₂,₃,₄,₅,₆,₇,₈,₉
常用元素,H/氢,C,N,O,Na,Mg,Al,P,S,Cl,K,Ca,Mn,Fe,Cu,Zn,Ag,Ba
```


## 已知问题

- **「摩有全都有」中的微粒数 `N`**：当前实现把 `N` 与物质的量 `n` 直接等同（未按 `N = n × 6.02×10²³` 换算），
  填入微粒数时结果不正确；其余物理量（`n`/`m`/`M`/`V`/`c`）的联动关系正确。
- **反应条件不参与校验**：`=点燃=` 中的条件仅原样保留，程序不判断该条件是否合理。
- **不判断反应是否真实存在**：只检查质荷守恒，不保证反应在化学上会发生。
- **无穷解搜索有上限**：极复杂的体系可能返回「无法配平」，需要人工判断。
- **遗留代码**：`Forms/Tutorial.cs` 与部分旧的快捷输入按钮处理器已无入口（界面上的对应按钮在早前版本中已移除）。
